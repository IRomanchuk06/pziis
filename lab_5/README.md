# Лабораторная работа 5. Управление ключами

Дискретное возведение в степень по модулю, алгоритм Диффи-Хеллмана
(`p = 134041249`, `α = 7`), дискретное логарифмирование
(baby-step giant-step) и сравнение времён выполнения.
Реализация — Python 3.12 (только стандартная библиотека),
выполнение — целиком в Docker-контейнере `python:3.12-slim`.

## Как запустить

```bash
cd lab_5
./run.sh
```

Одна команда: собирает образ `lab5:latest` (docker compose, проект
`lab_5`), запускает демонстрацию в контейнере и сохраняет вывод.

Требования: `docker` + `docker compose` v2 (на хосте больше ничего
не нужно и ничего не устанавливается).

## Структура

```
lab_5/
├── app/
│   ├── main.py        # сценарий демонстрации (4 шага + сводка)
│   └── modmath.py     # mod_pow, BSGS, Миллер-Рабин, порядок группы
├── Dockerfile         # FROM python:3.12-slim
├── docker-compose.yml # сервис lab5, проект lab_5
├── run.sh             # сборка + запуск + сохранение вывода
├── demo_output/
│   └── lab5_output.txt  # реально захваченный вывод прогона
├── report/
│   └── report.md      # отчёт (постановка, алгоритмы, результаты, вывод)
└── README.md
```

## Что выводит программа

1. Собственное быстрое возведение в степень vs встроенная `pow(b,e,m)`
   — совпадение результатов и сравнение времени.
2. Диффи-Хеллман: X1, X2, Y1, Y2, общие секреты `(Y1)^X2` и `(Y2)^X1`
   и проверка их равенства (плюс проверка простоты `p` и порядка `α`).
3. BSGS-логарифмирование: восстановление случайного `X` и обоих
   секретных ключей ДХ по открытым `Y1`, `Y2`.
4. Таблица времён: mod_pow / pow / BSGS (`time.perf_counter`).

Примечания:

- ГПСЧ зафиксирован (`SEED = 2026`), поэтому X1, X2 и все производные
  значения воспроизводимы от запуска к запуску; времена зависят от
  машины.
- Контейнер запускается от uid текущего пользователя, поэтому файл в
  `demo_output/` не принадлежит root.

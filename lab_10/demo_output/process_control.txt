
==================================================================
ШАГ 15. Запуск файлов filex5 от iit11 и проверка остановки (kill)
==================================================================

Файлы file15/file25/file35/file45/file55 имеют права «только выполнение»,
поэтому их прямой запуск (./файл) в Linux невозможен: интерпретатор
#!/bin/bash обязан открыть файл на чтение. Ниже для каждого файла
фиксируется результат прямого запуска, затем процесс реально запускается
от имени iit11: root читает файл и передаёт его текст bash процесса iit11
через fifo (унаследованный дескриптор stdin — проверка прав происходит при
открытии файла, а не при чтении из уже открытого дескриптора).
Процесс iit11 останавливается на команде 'read testVariable'.

Проверяемые: iit11, iit12, iit21, iit22, iit3, root (плюс iit21 через sudo).

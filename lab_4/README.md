# Лабораторная работа № 4. Генерация случайных чисел (БГУИР)

Вся работа выполняется **внутри docker-контейнеров** — на хосте достаточно
docker/docker compose, ничего устанавливать и запускать не нужно.

## Запуск

```bash
./run.sh
```

Одна команда: собирает образы, компилирует C++-программы (g++ и MinGW),
генерирует файлы датчиков, прогоняет анализы (программа «Expert» + простые
тесты), сохраняет весь вывод в `demo_output/` и делает best-effort попытку
запуска Windows-.exe (CryptGenRandom) под wine.

Требования: docker + docker compose, пользователь в группе docker.
Размеры образов: `lab_4:lab4` ≈ 1.0 ГБ, `lab_4:winetest` (с wine) ≈ 1.8 ГБ.

## Что делает demo (в контейнере)

1. Компилирует `cpp/gen_msvc.cpp` и `cpp/gen_own.cpp` (g++), кросс-компилирует
   `cpp/gen_crypt.cpp` → `bin/gen_crypt.exe` (MinGW, CryptoAPI, `-ladvapi32`).
2. Генерирует данные: 20 МБ младших байтов `rand()` (MS VS), 12 МБ своего
   генератора (формула (1) таблицы 1 методички: `x_{t+1} = (1176·x_t +
   1476·x_{t-1} + 1776·x_{t-2}) mod (2^32−5)`), эталон 1 МБ `/dev/urandom`,
   архив `.zip` исходников (python `zipfile`).
3. Прогоняет программу «Expert» (`tools/expert.py`: хи-квадрат, 256 степеней
   свободы, p-значение через регулярную верхнюю неполную гамма-функцию на
   чистом `math`, вердикты как в методичке) на всех файлах, включая бинарники.
4. Прогоняет простые тесты (`tools/extra_tests.py`): частотный, пар байтов,
   longest run (NIST, M=128).
5. Запускает `bin/gen_crypt.exe` под wine-8.0 в контейнере (сервис `winetest`,
   1 МБ через CryptGenRandom) и пересчитывает таблицы с учётом результата.

## Структура

```text
cpp/            исходники C++ (генераторы)
tools/          python-анализаторы (Expert, доп. тесты, zip, таблица)
scripts/        скрипты, выполняемые внутри контейнера
demo_output/    ТОЛЬКО реально захваченный вывод программ:
  build.log           компиляция g++ и MinGW
  generate.log        генерация файлов данных
  expert_results.txt  результаты «Expert» (файл / chi2 / p / вердикт)
  extra_tests.txt     частотный, пар байтов, longest run
  summary_table.md    сравнительная таблица всех файлов
  cryptgen_wine.txt   журнал запуска CryptGenRandom под wine
  run.log             полный журнал ./run.sh
  data/               сгенерированные файлы данных
report/         report.md — полный отчёт
```

## Статус CryptGenRandom

`gen_crypt.exe` **скомпилирован** (MinGW 12-win32, см. `demo_output/build.log`)
и **запущен** под wine-8.0 в docker (см. `demo_output/cryptgen_wine.txt`,
`CRYPTGEN_RESULT: OK`): получен `demo_output/data/crypt_out.bin` (1 МБ) и
проанализирован. Предупреждение «wine32 is missing» в начале журнала
не мешает: .exe 64-битный. Резервный вариант (если wine недоступен — например,
на ARM-хосте): запустить `bin/gen_crypt.exe` в Windows (ВМ), положить результат
в `demo_output/data/crypt_out.bin` и выполнить `docker compose -p lab_4 run --rm lab4
bash /work/scripts/run_analysis.sh` — таблицы пересчитаются автоматически;
вывод программы при этом никогда не выдумывается.

## Примечание о вердиктах «Expert»

Методичка задаёт формулировки вердиктов («не является случайной»,
«подозрительна», «почти подозрительна»), но не числовые пороги. В реализации
использованы стандартные двусторонние уровни значимости 1 % / 5 % / 10 %
(подробности — в `report/report.md`, п. 2.2).
